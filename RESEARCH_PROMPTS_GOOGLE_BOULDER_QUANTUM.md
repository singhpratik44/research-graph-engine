## Pro Tips

**Tip 1: Use Google Scholar "Alerts"**
- Set up alerts for: "Google Quantum" + "Boulder" + "error correction"
- Get notified when new papers appear

**Tip 2: Check Publication Dates**
- Recent papers = bleeding edge research
- If paper is from 2022, they've moved on by now
- Focus on 2024-2025

**Tip 3: Follow Citation Chains**
- Find one Google Boulder paper
- Look at what it cites (foundational work)
- Look at who cites it (recent work building on theirs)

**Tip 4: ArXiv Preprints vs Published**
- arXiv = published first, often 3-6 months before journal
- So if you see a 2024 arXiv paper, it's the latest
- Journal version comes later

**Tip 5: Save Everything**
- Screenshot abstracts
- Save links to papers
- Note researcher names
- You'll reference these in cover letter + interview
