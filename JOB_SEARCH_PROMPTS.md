## Backup Search Strategy (If Direct Search Fails)

**If you can't find the job on company board:**

### Google Jobs Aggregator
```
https://www.google.com/search?q="[company]" "[job title]" jobs 2024
- Add: site:linkedin.com/jobs for LinkedIn results
- Add: site:indeed.com for Indeed results
```

### Indeed Search
```
https://www.indeed.com/jobs?q=[job title]&l=[location]
- Filter: Company = [target company]
- Filter: Recent (last 7 days)
```

### LinkedIn Search
```
https://www.linkedin.com/jobs/search/?keywords=[job title]&companies=[company ID]
- Filter: Posted date (recent)
- Filter: Location
```

### Company News / Press Release
```
[Company] + "hiring" + "quantum" OR "security"
- Check company blog for job announcements
- Look at recent LinkedIn posts from hiring managers
```

## Pro Tips

**1. LinkedIn Filters**
- Filter by: "Posted in last 7 days" (catches fresh postings)
- Filter by: "Easy Apply" (faster submission)
- Save job searches (LinkedIn remembers your searches)

**2. Company Job Board Quirks**
- AWS: use "Quantum" keyword, may be under "AWS" or "Amazon Web Services"
- Google: check multiple locations (roles may be NYC, Seattle, Mountain View)
- IBM: check "IBM Quantum" section separately from main careers
- Startups (Atom, IonQ, PsiQuantum): roles may be listed under "Engineering" broadly

**3. If Exact Job Doesn't Exist**
- Apply to closest match (e.g., "Senior Software Engineer" if "Principal" unavailable)
- Still use customized resume/cover letter for that role
- Note in cover letter: "This aligns with my Technical Lead / Principal background"

**4. Save Everything**
- Screenshot job posting (text + requirements)
- Save URL
- Note hiring manager name (if listed)
- Note job ID (useful for follow-up)
